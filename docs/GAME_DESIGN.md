# Game design

## Premise

Every operator connects to the same emergency but receives a different version of it. Information is not flavor text; it changes which actions appear safe, possible, or necessary.

## Principles

- Each role contributes evidence and capabilities that other roles cannot replace.
- Contradictions are generated by explicit scenario rules, never arbitrary random lies.
- Verification consumes time, power, integrity, or role-specific capacity.
- The system may accuse a player without turning the game into a standard hidden-traitor design.
- Final decisions can be private, but the server alone calculates their outcome.

## Roles

Operations controls access and station topology. Surveillance interprets cameras and sensors. Engineering routes power. Archives verifies historical records. Communications traces signals. Diagnostics compares system integrity and time.

Two to five players receive data-driven role bundles; six players receive one role each.

## First vertical slice

The C03 slice demonstrates the core loop with Operations and Archives before expanding ORPHEUS-17. It is complete only when role-specific projection, server authority, replay protection, reconnect, and browser isolation work together.
