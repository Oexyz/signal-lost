# Roadmap

The roadmap describes intended work, not completed functionality.

## Phase 0: Protocol Boot (active)

- repository and pnpm workspace foundation;
- design tokens and public interface baseline;
- versioned client-safe protocol boundary;
- deterministic contradiction-engine slice;
- local setup, audits, documentation, and continuous integration.

## Phase 1: First Contact

- invite-only lobby;
- WebSocket session lifecycle;
- two-player role assignment;
- first live role-specific projections;
- playable C03 mini-round.

## Phase 2: Contradiction

- canonical world model;
- projection rules and reality drift;
- event persistence and reconstruction;
- secure reconnect.

## Phase 3: Station Systems

- all six role capabilities and distinct interfaces;
- energy, integrity, verification, and cooldown resources;
- shared Evidence Board.

## Phase 4: ORPHEUS-17

- complete mission phases, events, endings, accessibility, and local audio.

## Phase 5: Hostile Client

- permission, replay, sequence, rate-limit, and information-isolation suites.

## Phase 6: Stability

- multiplayer browser tests;
- load testing;
- performance, accessibility, and device validation.

## Phase 7: Public Signal

- reviewed production infrastructure;
- deployment pipeline and service observability;
- legal, privacy, asset-license, and youth-protection review;
- first public pre-release.
