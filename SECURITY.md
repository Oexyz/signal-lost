# Security policy

## Supported versions

SIGNAL//LOST has not published a release. Security fixes currently target the active development branch.

## Reporting a vulnerability

Do not publish suspected vulnerabilities in a public issue, discussion, scenario, or pull request.

Send sensitive findings to `security@oexyz.de`. If email is unsuitable, request an alternate private channel without disclosing the vulnerability in a public issue.

Include only the information needed to reproduce the problem:

- affected component and revision;
- impact and required preconditions;
- minimal reproduction steps;
- whether player projections, session credentials, or canonical scenario data may be exposed.

Do not include live credentials, private room data, or personal data. No response deadline, bounty, payment, or legal safe-harbor program is currently promised.

## Security model

The current trust boundaries and known limitations are documented in [docs/SECURITY_MODEL.md](docs/SECURITY_MODEL.md).
